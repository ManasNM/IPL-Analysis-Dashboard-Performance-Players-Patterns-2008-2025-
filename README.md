# 🏏 IPL Analysis Dashboard: Performance, Players & Patterns (2008–2025)

## 📊 Project Overview

This repository includes an interactive Power BI dashboard analyzing the Indian Premier League (IPL) from **2008 to 2025**.  
The project focuses on uncovering insights related to team performance, player statistics, and season-wise trends using real match data.

---

## 📁 Dataset Source

- Dataset sourced from Kaggle  
- Covers IPL seasons from **2008 to 2025**  
- Includes match-level and ball-by-ball data  

👉 Kaggle Dataset:  
[IPL Dataset Analysis (2008–2025)](https://www.kaggle.com/code/genieincodebottle/ipl-dataset-analysis-2008-2025)

## 🧹 Data Cleaning & Transformation

Data preprocessing was performed using Power BI (Power Query):

- Removed unnecessary and empty columns  
- Handled type mismatch errors  
- Converted columns to appropriate data types  
- Cleaned null and inconsistent values  
- Created calculated measures using DAX:  
  - **Strike Rate = (Runs / Balls Faced) × 100**

---

## 📌 Dashboard Structure

### 🔹 Page 1: Overview

Provides a high-level summary of IPL:

- Total Matches Played  
- Total Runs Scored  
- Total Wickets Taken  
- Total Sixes Hit  
- Season-wise performance trends  
- Team-wise comparisons  
- Toss decision insights  

---

### 🔹 Page 2: Player Analysis

Focuses on individual player performance:

- Top Run Scorers in IPL  
- Top Wicket Takers in IPL  
- Most Sixes by Player  
- Top Strike Rate Players  
- IPL Runs Trend Over Seasons  

---

## 📈 Key Insights

- Run scoring has increased steadily over seasons  
- A few players consistently dominate IPL performance  
- Power hitters significantly influence match outcomes  
- Strike rate highlights aggressive batting styles  
- Clear distinction between top and average bowlers
